# 모음 자동 수집 플러그인

처음에만 모음에서 만든 연결 코드와 현재 파일 공유 링크를 입력합니다. 이후 이 기기에서 같은 파일의 플러그인을 실행하면 저장된 연결로 자동 인증하고, 마지막 정상 상태와 현재 파일을 비교합니다.

실행 중에는 documentchange로 변경된 노드를 모아 약 5초마다 서버로 직접 보냅니다. 모음 웹사이트가 닫혀 있어도 동작하며, 네트워크 오류는 자동 재시도합니다. 모음 변경사항은 수동 새로고침 없이 약 5초마다 갱신됩니다.

플러그인을 닫으면 수집이 멈춥니다. 닫혀 있는 동안의 개별 편집 이력은 복원하지 않습니다. 기기에 연결 정보와 작은 실패 배치를 저장하고, 큰 실패 배치는 재실행 때 현재 최종 상태 비교로 보완합니다.

토큰은 프로젝트·소유자·파일에 제한되며 서버에는 해시만 저장됩니다. 최초 발급 후 8시간이 지나면 만료되고, 새 연결 코드 발급/웹 연결 해제는 기존 토큰을 무효화합니다. 만료 시 새 코드로 재연결해야 합니다. heartbeat로 만료를 연장하지 않습니다. 일반 플러그인에서 fileKey가 제공되지 않으면 실제 열린 파일과 입력 링크가 같은지는 직접 확인해야 합니다.

설치 스크립트는 기존과 같습니다. `install.ps1 -Destination "manifest.json이 있는 폴더"`는 플러그인 ID를 유지합니다. 백엔드 DB 변경과 배포를 먼저 완료한 후 플러그인을 업데이트하세요.

상세 API·DB·배포 안내: [docs/figma-live-plugin.md](../docs/figma-live-plugin.md).

테스트: `node --test figma-plugin/tests/plugin.test.mjs`.
